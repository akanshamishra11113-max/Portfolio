# 🌐 Personal Portfolio Website

This is a simple multi-page personal portfolio website built using HTML and CSS.

## 📌 Features

* Clean and responsive design
* Navigation bar with multiple sections
* Sections included:

  * About Me
  * Skills
  * Experience
  * Education (opens in a separate page)
* Beginner-friendly project

## 📂 Project Structure

```
portfolio/
│── index.html        # Main portfolio page
│── education.html    # Education page
│── README.md         # Project documentation
```

## 🚀 How to Run

1. Download or clone the repository
2. Open `index.html` in your browser
3. Click on navigation links to explore

## 🔗 Navigation

* **Home:** Main page
* **Education:** Opens a separate HTML file using hyperlink
* Other sections scroll within the page

## 🛠️ Technologies Used

* HTML5
* CSS3
